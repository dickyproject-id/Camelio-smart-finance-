# 🕵️‍♂️ CARA MENGAMBIL DATA CSV RAHASIA (AKURASI OCR)

Data hasil *scan* struk AI (Ground Truth vs Prediksi) diam-diam disimpan ke dalam file **Excel/CSV** di penyimpanan internal HP Anda agar tidak merusak tampilan antarmuka (UI) aplikasi.

Karena letaknya yang tersembunyi, sistem menyediakan "Jalan Pintas Rahasia" (*Hidden Gesture*) untuk memunculkan dan membagikan file tersebut. Berikut adalah langkah-langkahnya:

## 📜 Langkah-Langkah Ekspor Data CSV

1. **Buka Aplikasi Camelio:** Jalankan aplikasi *Smart Finance App* di HP Anda.
2. **Masuk ke Halaman AI:** Pada menu utama (Dashboard), cari dan klik fitur **"Analisis AI"** (yang berwarna ungu).
3. **Temukan Area Rahasia:** Perhatikan judul halaman **"Analisis AI"** (atau "AI Insight" jika dalam bahasa Inggris) yang berada di bagian paling atas (*AppBar*) layar.
4. **Tekan dan Tahan (Long Press):** Tekan dan tahan jari Anda tepat di atas tulisan judul **"Analisis AI"** tersebut selama **1 - 2 detik**.
5. **Kirim/Ekspor File:** 
   - Sebuah menu bagikan bawaan dari HP Anda (Share Menu) akan otomatis muncul dari bawah.
   - Anda akan melihat file dengan nama `receipt_accuracy_log.csv`.
   - Silakan bagikan file tersebut ke **WhatsApp**, **Telegram**, **Email**, atau simpan ke **Google Drive** Anda.
6. **Buka di Laptop:** Unduh file CSV tersebut di laptop Anda, lalu buka menggunakan **Microsoft Excel** atau **Google Sheets**. Anda sekarang bisa mengisi kolom "Harga Asli (Ground Truth)" dan "Status" secara manual untuk kebutuhan skripsi atau laporan Anda.

---

### ⚠️ Catatan Tambahan
* Jika saat tulisan "Analisis AI" ditahan (long press) lalu muncul pop-up peringatan hitam bertuliskan *"File CSV belum ada"*, itu artinya Anda belum pernah melakukan scan struk menggunakan AI sejak fitur mata-mata ini dipasang. Silakan lakukan scan struk minimal 1 kali terlebih dahulu!
* Proses ekspor ini sama sekali tidak menggunakan memori cloud atau kuota internet (kecuali saat mengirim via WA/Email). Data sepenuhnya bersumber dari penyimpanan lokal HP (Offline).
